# BREWBOX - Landing Page

A responsive static landing page for BREWBOX, a fictional coffee subscription brand.
Built for the Web Development Internship at **Oasis Infobyte** (#oasisinfobyte).

## Tech Stack

- HTML5
- CSS3 (Flexbox and Grid)
- Google Fonts (Poppins, Inter)
- No JavaScript

## Features

- Sticky navigation bar with links to every section
- Hero section with headline, subheadline and call-to-action button
- Features section (3 cards), About section with stats, Testimonials section
- Footer with placeholder contact and social links
- Consistent brown and caramel colour palette
- Fully responsive layout (desktop, tablet, mobile) with smooth scrolling

1. Download or clone the repository.
2. Open `index.html` in any modern web browser. No installation needed.
